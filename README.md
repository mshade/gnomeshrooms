# Gnome & the Black Cats 🍄

A relaxing little game. You are a gnome on a quiet walk through a dense,
flower-filled forest, picking mushrooms. Two black cats follow you the whole
way: **Frankie** (the slightly bigger one, with an overbite) and **Pickle**.

That's it. That's the game.

## How to play

Open `index.html` in any browser:

```sh
open index.html
```

(or just double-click it in Finder)

## Controls

| Key | Action |
|-----|--------|
| WASD / arrow keys | Walk |
| Space or E | Pick a nearby mushroom |
| M | Toggle forest sounds |

There are four mushroom varieties to collect — Red Cap, Brown Bell,
Chanterelle, and the rare Violet Whim. Picked mushrooms regrow elsewhere in
the forest after a while. There is no timer, no enemies, and no way to lose.

No dependencies, no build step — it's a single HTML file and one script,
with all the art drawn in code.
